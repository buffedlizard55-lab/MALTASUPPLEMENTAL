# Malta Trip Guide

A mobile-friendly, source-linked guide for the traveler-supplied trip window **13–19 October 2026**, based at **AX ODYCY, Qawra Coast Road, Qawra SPB 1902** (Deluxe Sea-View room supplied as a planning input). The traveler supplied “BLAST Arena Studios, Attard” as the event destination, and that destination is now **confirmed from the event’s own ticketing listing** — BLAST Arena Studios Malta, MFCC South Gate National Stadium, ATD 4000 Ħ’Attard, 14–18 October 2026, listed as free with a required reservation, in person, ages 18+. What is still *not* confirmed is the traveler’s own reservation, the attendee gate inside the site, the nine FAQ answers, and the Saturday/Sunday door times.

**Published guide:** <https://buffedlizard55-lab.github.io/MALTASUPPLEMENTAL/>

The official Thunderpick page gives the overall 12–19 October operational window (arrival 12th, media day 13th, group stage 14–16th, playoffs 17–18th, departure 19th), so the supplied 13–19 October stay covers all five match days and **13 October is a genuine free day**. The event’s own ticketing listing publishes check-in/games times for three of the five days and labels the event Free, in person and 18+. See the source log and open questions for the dated evidence and limits.

**The headline transport finding: the bus gets you there, and it will not bring you back.** Route 186 from Qawra clears even the 09:30 check-in, but the venue day is listed to 22:30 while the last departure toward Buġibba was 20:53 — and that direction serves *no* Il-Qawra stop at all, so even catching it means a mandatory second boarding. No verified night route reaches Ta’ Qali. Plan a pre-booked taxi or ride-hailing return for the event evenings, watch for a possible TQ special service, and compare the quote against Transport Malta’s published maximum meter rates.

This is a dated research and planning aid—not a booking, admission, fare, service, radio reception, or programme-carriage guarantee.

## Key findings and limits

- **Event, venue and ticket listing — confirmed from the event’s own pages:** the ticketing listing gives BLAST Arena Studios Malta, MFCC South Gate National Stadium, ATD 4000 Attard (pin 35.8957343, 14.4168839), Wednesday 14 – Sunday 18 October 2026, the price label **Free** with a “Reserve a spot” action, “In person”, “ages 18+” and a “Sales end soon” notice. Published agenda: Wed 14 and Thu 15 check-in 09:30 / games 10:30, day listed to 22:30; Fri 16 check-in 14:00 / games 15:00, day listed to 21:00; Sat/Sun did not render and the header’s 22:00 conflicts with the Wed/Thu 22:30 rows. This is dated listing evidence, not proof of current inventory, the traveler’s own reservation, per-day scanning or the attendee gate. Thunderpick’s official page gives the wider 12–19 October operational window, the format, the $1,000,000 prize split and the internet streams — broadcast streams are not radio.
- **Event-day return risk — the headline constraint:** the listed 22:30 finishes on 14–15 October (and 21:00 on 16 October) outlast the last listed Route 186 departure from the venue-side Stadium stop 2194 toward Buġibba (20:53). That direction serves **no** Il-Qawra stop and terminates at Buġibba Bay 1, so a bus return always needs a second boarding, and no night route was verified to serve Ta’ Qali or Attard. The return is therefore planned as a taxi/ride-hailing journey. One wildcard remains: MPT’s TQ special event services (TQ1’s corridor runs through Qawra at the €3.00 Special Services fare) — the TQ1 page showed “Timetable not available!” and no TWC notice was found, so check the service-updates page daily during 14–18 October.
- **Event-day transport and fares:** Route 186 is the bus candidate between the Qawra seafront stops (Arznell 950 / Luzzu 951 / Qawra 952) and Ta’ Qali Stadium 6227; the return uses opposite-side Stadium stop 2194 toward Buġibba, not the Qawra seafront, and the dated onward connection and safe walks are unverified. Route 214 is an alternative to check; MPT publishes two 17 October diversion windows (19:00–00:00 and 20:00–24:00 — plan for the union). The official fare table lists €2.50 summer / €2.00 winter singles, but its only stated winter validity ends 13 June 2026, so the applicable 13–19 October 2026 single is **not established**; card prices (€19 / €21 / €25 / €27) are comparisons, not an assumed purchase. For the planned taxi return, Transport Malta publishes maximum meter rates (initial €3.50, then €2.50/km falling to €0.85/km beyond 20 km, plus waiting/traffic charges) — but that page was last updated 06/04/2022, the road distance was not measured, and the worked caps are arithmetic, not quotes. Bolt is documented in Malta; sources conflict on Uber.
- **Sports radio:** Malta-receivable evidence remains qualified. Radio in Malta labels “Sports Channel (Talk Sport)” on 6C (185.360 MHz); 2025 scanner-directory observations also point to 6C, while WorldDAB’s table lists a generic “Sports Channel” on 12A and the local operator directory lists no sports service. These are scan leads, not proof of current reception, identity or commentary. Official BBC episode records name seven UK Premier League commentaries for 17–18 October (including Bournemouth–Sunderland on 5 Sports Extra 2), but that UK schedule does not prove Malta carriage, BBC World Service output or stream access. NET FM’s grid and Rai’s weekend show are recurring schedules, not a trip-week named-match guarantee. A US HD Radio set cannot decode DAB+; the BBC advises using a DAB+ set purchased in Malta.
- **Kalshi, fixtures and eligibility:** EPL/Serie A category pages list trip-window fixtures that overlap the radio windows. Kalshi’s own help centre says trading from outside the United States is possible from many countries and that customers may use the platform while travelling abroad, subject to its Member Agreement and geographic requirements; third-party guidance conflicts, saying access is limited to US residents who pass KYC and warning of temporary geo-blocking while travelling. A market or fixture listing is still not proof of Malta radio commentary or of a market-to-broadcast link; confirm eligibility with Kalshi support.
- **Hotel environmental contribution:** the 2026 MTA guideline PDF lists €1.50 per night for eligible guests aged 18+, capped at €22.50 per person per visit, with separate receipt disclosure. The current MTA webpage separately refers to nights that “exceeded fifteen (15) nights”; the two official texts do not expressly reconcile that wording for short stays. Six nights × €1.50 is conditional arithmetic only, not a confirmed liability or planner default; ask MTA/AX ODYCY and use the invoice.
- **Expense planner:** all budget and actual fields start blank, including the seven optional daily templates. Two tools cover the itinerary hand-off: a documented “when your itinerary arrives” intake list, and a **paste-your-itinerary quick-fill** panel that previews which row each line would fill and writes only to still-blank budget fields — typed amounts are never overwritten, and unresolved lines are reported back instead of guessed. Enter euros on a consistent whole-trip/party basis and avoid counting the same expense in an aggregate and daily row. Inputs autosave only in this browser/device, are not sent to a server, can be exported as CSV (or downloaded blank as a template), and can be cleared. Verified bus/card prices are available as a transport benchmark; reference URLs are still not quotes.
- **Customs:** duty-free allowances into Malta (€430 by air/sea on goods, plus alcohol and tobacco limits, with a lower tobacco limit possible in some member states) come from the European Union’s official travellers’ page; the return leg uses U.S. Customs and Border Protection’s $800 returning-resident exemption (48 hours abroad, once every 31 days, 200 cigarettes / 100 cigars) and its declare-everything guidance. Check the Maltese customs authority for anything unusual.

Yelp, Instagram, TikTok, Facebook, X, and Reddit access was blocked or limited in the recorded checks; five 403 responses in one batch lacked reliable endpoint labels. Official X post text was extracted but its attached opening-day schedule image was not readable. Coverage is not comprehensive; see the dated source notes.

## Build, preview, and deployment

The site is static HTML, CSS, and JavaScript with JSON data; it has no production build step or runtime dependency installation. Repository Pages settings publish the `main` branch root. Merging to `main` updates the public site through GitHub Pages. The `.nojekyll` file keeps the source/data tree static. GitHub Actions validates pull requests and pushes to `main`; the workflow is separate from Pages publishing.

For a local HTTP preview from the repository root:

```bash
python3 -m http.server 8080 --bind 0.0.0.0
# Open http://localhost:8080
```

An HTTP server is needed for browser `fetch()` and expense-planner `localStorage`. The deployed planner saves only in the current browser/device; export a CSV before switching devices or clearing browser data.

The offline validator checks JSON/schema/enums across the seven datasets, source-log URL coverage (every cited URL must be logged), JavaScript syntax, topic-page/data wiring, and local paths/navigation including record anchors. It is not an external URL crawler or a guarantee of current external facts.

## Browser and regression tests

Development tests use Node.js 22+, Python 3, and npm-distributed headless Chromium (Linux x64):

```bash
npm ci

```

The suite checks the nine active pages — including the CS2 event guide — at 320/360/768/1440 px, responsive overflow, axe WCAG 2A/AA/2.1AA rules, data/render parity for every record field, navigation/deep links, filtering, expense persistence/CSV/reset, invalid amounts, denied/corrupt storage, and data-fetch failures. It does not test physical radio reception, external booking availability, personal eligibility, every browser/device, or exhaustive assistive-technology compatibility. Generated screenshots/reports and `node_modules` are ignored.
