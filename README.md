## Key findings and limits

- **Event and venue:** the official Thunderpick page lists the 12–19 October event window and Malta as its location. The Thunderpick release names BLAST Studios Malta; MFCC/Ta’ Qali is venue-area context from a BLAST guide for a different event, not a confirmed TWC address/pin. Public spectator access, ticket arrangements, door times, and the event-day entrance remain unconfirmed.
- **Event-day transit:** Route 186 is the leading public-bus corridor between Qawra and Ta’ Qali; Route 214 is an alternate to compare. MPT’s static listing shows Qawra stop 952 at 06:10–21:38. The normal Rabat-to-Buġibba return runs via St Paul’s Bay/Buġibba, not the Qawra seafront, with a final listed arrival at Buġibba Bay 1 at 21:26—this is not a guaranteed hotel return. MPT also lists a 17 October evening diversion (19:00 to approximately midnight, omitting stops Gholja 2 through Targa toward Buġibba, alongside a separate Rabat Saqqajja stop construction closure); confirm the exact stops, walking segments, live timetable, and detour impact close to travel.
- **Radio & Kalshi markets:** NET FM is listed at FM 101 MHz and has recurring weekend sports shows; its grid does not explicitly state a time zone. Malta’s DAB+ directory lists Radio Sportiva and BBC World Service. WorldDAB (specialist technical directory) lists BBC World Service on Digi B Network block 6A at 181.936 MHz, but reception at the hotel/event venue is untested and Radio Sportiva’s current block/frequency was not found. BBC *Sportsworld* (Sat 17 Oct 15:06–18:59 CEST; Sun 18 Oct 16:06–19:59 CEST) and Radio Sportiva *Diretta Sportiva* overlap Kalshi’s 16–18 October EPL and Serie A kickoff windows, but match-by-match radio commentary, CS2/TWC or local-event radio carriage, and Kalshi trading access from Malta are not confirmed.
- **Weather & ETIAS (checked 11 October 2026):** the Malta Met Office 7-day forecast fetched 11 October covers 13–17 October (Tue 13 Oct isolated showers 26°C/19°C; Wed 14–Fri 16 Oct mainly sunny 24–25°C/17–18°C; Sat 17 Oct mainly cloudy 23°C/18°C; detailed forecast sea temperature 26°C), while Sun 18–Mon 19 October remain beyond the 7-day view. The official EU ETIAS page rechecked 11 October confirms ETIAS is still not in operation.
- **Hotel environmental contribution:** Malta Tourism Authority guidance checked 10 October states €1.50 per night per person aged 18+ from 1 July 2026, capped at €22.50 per eligible person per visit. Six chargeable nights would be €9 per eligible adult, conditionally; actual billable nights, guest ages, and the hotel invoice determine the amount. The planner does not prefill a personal charge.
- **Expense planner:** all budget and actual amounts start blank. Enter amounts in euros on a consistent whole-trip/party basis. The planner stores inputs in this browser/device only, does not send them to a server, exports a CSV backup, and can clear saved entries. Reference URLs are not price quotes.
- **Research-platform limits:** sampled TripAdvisor and a small number of Google Maps profile views informed parts of the food/activities research. Direct Yelp, Instagram, TikTok, Facebook, and X requests, and Reddit refreshes, were blocked or returned HTTP 403 in the relevant checks. Platform coverage is not comprehensive; see the dated notes in `docs/SOURCES.md` and the topic pages.
- **Open questions:** exact event access/times, saved date-specific transit route and return, 17 October diversion impact, trip-week radio schedule/carriage, current business hours/status conflicts, traveler-specific entry/insurance/device details, and the booking itinerary remain unresolved as noted in `docs/OPEN_QUESTIONS.md`.

## Build, preview, and deployment

The site is static HTML, CSS, and JavaScript with JSON data; no application build or dependency installation is required. Repository Pages settings checked on 9 October 2026 publish the `main` branch root to the public site. Merging changes to `main` updates the site through GitHub Pages’ existing branch-based publishing. The `.nojekyll` file keeps the source/data tree static. A GitHub Actions workflow validates pull requests and pushes to `main`; it does not replace the configured Pages publisher.

For a local HTTP preview from the repository root:

```bash
python3 -m http.server 8080
# Open http://localhost:8080
```

An HTTP server is needed for browser `fetch()` and the expense planner’s `localStorage` behavior. The deployed planner saves only in the current browser/device; export a CSV before switching devices or clearing browser data.

The Pages workflow and local validator check the exact 13-field record schema and enums, HTTPS primary URLs and their source-log coverage, JavaScript syntax, topic-page/data wiring, and local links. External websites are not guaranteed to remain available; re-open primary sources before acting on date-sensitive information.
