# Malta Trip Guide

A mobile-friendly, source-linked guide for the traveler-supplied trip window **13–19 October 2026**, based at **AX ODYCY, Qawra Coast Road, Qawra SPB 1902** (Deluxe Sea-View room supplied as a planning input). The traveler supplied “BLAST Arena Studios, Attard” as the event destination; this is not confirmation of a ticket, public access, exact entrance, or a TWC-specific location pin.

**Published guide:** <https://buffedlizard55-lab.github.io/MALTASUPPLEMENTAL/>

The official Thunderpick page lists the overall 2026 event window as 12–19 October (arrival 12th, media day 13th, Group Stage 14–16th, Playoffs 17–18th, departure 19th) and gives Malta as the location. A Thunderpick-issued release names BLAST Studios Malta and is datelined Ta’ Qali. BLAST’s own guest guide and VisitMalta’s directory list the studio’s postal address at the Malta Fairs & Conventions Centre, Ta’ Qali, ATD 4000 Ħ’Attard; the release supports the event’s venue/locality context, not a precise postal address or attendee entrance. They do not establish this traveler’s TWC ticket, attendee gate, public entrance or daily door times. A separate open PR #37 cites an Eventbrite listing that was not independently reviewed here; see the dated caveat in the source log and open questions.

This is a dated research and planning aid—not a booking, admission, fare, service, radio reception, or programme-carriage guarantee.

## Key findings and limits

- **Event, venue and admission:** The official Thunderpick page lists the 12–19 October window and Malta. BLAST’s guest guide and VisitMalta’s directory list the BLAST Arena Studios postal address at MFCC, Ta’ Qali, ATD 4000 Ħ’Attard; Thunderpick’s Ta’ Qali-datelined release names the studio but is not a precise-address or attendee-gate source. This does not establish a TWC ticket or access. The checks documented on 11 October found no public ticket sale, but that dated negative search is not proof a listing does not now exist. A separate open PR #37 cites an Eventbrite page that this audit did not fetch or verify; see OQ-26. A secondary report quotes Thunderpick as saying matches stream on Twitch, Kick and YouTube. Confirm current ticket terms and access with the organizer.
- **Event-day transport and prices:** Route 186 is a public-bus candidate from Qawra stop 952 to Ta’ Qali Stadium stop 6227; its return uses opposite-side Stadium stop 2194 toward Buġibba, not the Qawra seafront. Static timetable variants lack reliable day-type context; the 17 October diversion’s practical effect and the date-specific return remain open. MPT lists €2.50 summer / €2.00 winter day-route singles, but its only explicit winter period ends 13 June 2026; the applicable 13–19 October 2026 fare is not stated. Card prices and terms are comparisons, not a personal trip estimate. Recheck MPT/tallinja and use the live planner after the organizer confirms the gate and schedule.
- **Sports radio:** Radio in Malta’s specialist directory labels a DAB+ 6C (185.360 MHz) service “Sports Channel (Talk Sport)”; Wikipedia separately lists talkSPORT on 6C. WorldDAB separately lists a generic “Sports Channel” on Digi B 2 / 12A (223.936 MHz), and the Malta DAB+ operator’s own directory lists no sports service. Block, identity, schedule, reception and match carriage are unverified. BBC World Service is listed on 6A; official Sportsworld episodes have 17–18 October times but general live-sport descriptions, not named-match schedules. NET FM’s recurring sports grid and Vibe FM’s domestic-league partnership remain distinct evidence. US HD Radio cannot decode DAB+; the BBC advises using a DAB+ receiver purchased in Malta.
- **Kalshi, fixtures and eligibility:** EPL/Serie A category pages list trip-window fixtures that overlap the radio windows. Kalshi’s own help centre says trading from outside the United States is possible from many countries and that customers may use the platform while travelling abroad, subject to its Member Agreement and geographic requirements; third-party guidance conflicts, saying access is limited to US residents who pass KYC and warning of temporary geo-blocking while travelling. A market or fixture listing is still not proof of Malta radio commentary or of a market-to-broadcast link; confirm eligibility with Kalshi support.
- **Hotel environmental contribution:** the 2026 MTA guideline PDF gives €1.50 per night for guests 18+ at visit start, capped at €22.50 per person per visit. The current MTA webpage separately refers to chargeable nights “that exceeded fifteen (15) nights,” and the official texts are not clearly reconciled for short stays. Six nights × €1.50 = €9 is conditional arithmetic only; ask MTA/AX ODYCY and use the invoice.
- **Expense planner:** all budget and actual fields start blank, including seven optional daily templates. A documented intake list and a paste-your-itinerary quick-fill panel help map confirmed items: preview first, fill only blank budget fields, never overwrite typed amounts, and report unresolved lines rather than guess. Entries autosave only in this browser/device, can be exported as CSV or a blank template, and can be cleared. Published bus/card prices are comparison points, not a confirmed October single fare or traveler-specific quote.
- **Customs:** duty-free allowances into Malta (€430 by air/sea on goods, plus alcohol and tobacco limits, with a lower tobacco limit possible in some member states) come from the European Union’s official travellers’ page; the return leg uses U.S. Customs and Border Protection’s $800 returning-resident exemption (48 hours abroad, once every 31 days, 200 cigarettes / 100 cigars) and its declare-everything guidance. Check the Maltese customs authority for anything unusual.
- **Research-platform limits:** sampled TripAdvisor and a small number of Google Maps profile views informed parts of the food/activities research. Yelp, Instagram, TikTok, Facebook, X, and Reddit access was blocked or limited in the recorded checks; five 403 responses in one batch lacked reliable endpoint labels. Official X post text was extracted but its attached opening-day schedule image was not readable. Coverage is not comprehensive; see the dated source notes.
- **Open questions:** current TWC ticket terms/attendee entrance/times (including an unverified Eventbrite lead cited by open PR #37); confirmed date-specific route and return; 17 October diversion impact; October single-fare applicability; measured stop/hotel/gate walks; DAB+ block/service identity, local reception and named-match carriage; Rai’s dated lineup; Malta access to BBC streaming; business-hour/ticket conflicts; traveler-specific entry, insurance, device and booking details; forecast updates; and MTA’s threshold wording. See [`docs/OPEN_QUESTIONS.md`](docs/OPEN_QUESTIONS.md).

## Build, preview, and deployment

The site is static HTML, CSS, and JavaScript with JSON data; it has no production build step or runtime dependency installation. Repository Pages settings publish the `main` branch root. Merging to `main` updates the public site through GitHub Pages. The `.nojekyll` file keeps the source/data tree static. GitHub Actions validates pull requests and pushes to `main`; the workflow is separate from Pages publishing.

For a local HTTP preview from the repository root:

```bash
python3 -m http.server 8080 --bind 0.0.0.0
# Open http://localhost:8080
```

An HTTP server is needed for browser `fetch()` and expense-planner `localStorage`. The deployed planner saves only in the current browser/device; export a CSV before switching devices or clearing browser data.

The offline validator checks JSON/schema/enums, source-log URL coverage, JavaScript syntax, topic-page/data wiring, and local paths/navigation. It is not an external URL crawler or a guarantee of current external facts.

## Browser and regression tests

Development tests use Node.js 22+, Python 3, and npm-distributed headless Chromium (Linux x64):

```bash
npm ci
npm test
```

The suite checks the eight active pages at 320/360/768/1440 px, responsive overflow, axe WCAG 2A/AA/2.1AA rules, data/render parity, navigation/deep links, filtering, expense persistence/CSV/reset, itinerary quick-fill preview/blank-only behavior, invalid amounts, denied/corrupt storage, and data-fetch failures. It does not test physical radio reception, external booking availability, personal eligibility, every browser/device, or exhaustive assistive-technology compatibility. Generated screenshots/reports and `node_modules` are ignored.
