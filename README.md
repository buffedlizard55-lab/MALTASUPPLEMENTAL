# Malta Trip Guide

A mobile-friendly, source-linked guide for the traveler-supplied trip window **13–19 October 2026**, based at **AX ODYCY, Qawra Coast Road, Qawra SPB 1902** (Deluxe Sea-View room supplied as a planning input). The traveler supplied “BLAST Arena Studios, Attard” as the event destination; this is not confirmation of a ticket, public access, exact entrance, or a TWC-specific location pin.

**Published guide:** <https://buffedlizard55-lab.github.io/MALTASUPPLEMENTAL/>

The official Thunderpick page lists the overall 2026 event window as 12–19 October (arrival 12th, media day 13th, Group Stage 14–16th, Playoffs 17–18th, departure 19th) and gives Malta as the location. A Thunderpick-issued release names BLAST Studios Malta. BLAST and venue listings provide MFCC/Ta’ Qali venue-area context for separate events, but do not confirm this traveler’s TWC spectator access, ticket, daily public door times, exact entrance, or transport. See the source log and open questions for the evidence boundaries.

This is a dated research and planning aid—not a booking, admission, fare, service, radio reception, or programme-carriage guarantee.

## Key findings and limits

- **Event, venue and admission — confirmed:** the event’s own ticketing listing gives **“Hotspawn present the Thunderpick World Championships 2026”, BLAST Arena Studios Malta, MFCC South Gate National Stadium, ATD 4000 Attard, Wednesday 14 – Sunday 18 October 2026, 9:30 AM–10 PM, in person, ages 18+, free tickets** via a “Reserve a spot” action. Published day agenda: Wed 14 and Thu 15 check-in 09:30 / games 10:30 (to 22:30); Fri 16 check-in 14:00 / games 15:00 (to 21:00); Sat 17 and Sun 18 remain unpublished. This supersedes the earlier “no public ticket sale found” position and the €10.00 BLAST-event ticket precedent. Thunderpick’s own page still describes the wider 12–19 October window and streams all matches on Twitch, Kick and YouTube.
- **The event outlasts the bus:** event days are listed to 22:00–22:30 while the last listed Route 186 departure from the Ta’ Qali Stadium area is 20:53, and MPT’s night routes cover Buġibba and Valletta, not Ta’ Qali. **A full event day has no bus return** — book a taxi or ride-hailing return.
- **Event-day transport and prices:** Route 186 is a direct public-bus candidate between Qawra stop 952 and Ta’ Qali Stadium stop 6227; its return boards from the opposite-side Stadium stop 2194 toward Buġibba, not the Qawra seafront (last listed Stadium departure 20:53). Route 214 is an alternative; MPT lists an evening diversion on 17 October. TD1’s timetable lists Il-Qawra Arznell stop 950 in both directions. **Fares were read directly from Malta Public Transport on 11 October 2026**: single day route €2.50 (summer table) / €2.00 winter with a two-hour transfer window, night and Tallinja Direct €3.00, TD1 €3.50, 12-journey card €19, Explore Adult 7-day €25, Explore Child €7, Explore Flex €21/€27, and a €50 fine without a valid ticket. Cards are sold at the Buġibba Terminal, the closest listed office to Qawra. Bolt is documented as operating in Malta; sources conflict on Uber. The exact door-to-door route, safe walks and late return still need a date-specific planner check. The operator’s page does not print the 2026/27 winter changeover, so €2.50 is the planning single fare.
- **Sports radio:** the strongest English-language lead is a DAB+ service named **“Sports Channel”**, which the Radio in Malta directory labels “Sports Channel (Talk Sport)” on **block 6C (185.360 MHz)** and Wikipedia’s talkSPORT article lists as “DAB+: 6C (Malta)” — while WorldDAB’s Multiplexes table lists a regular “Sports Channel” service on **block 12A (223.936 MHz)** and the Maltese operator’s own channel directory lists no sports service at all, so scan both blocks and listen before trusting the name. talkSPORT is an official Premier League audio broadcaster, which is why the lead is worth chasing. Block 6A (181.936 MHz) carries BBC World Service, whose dated *Sportsworld* episodes start about 15:06 on 17 October and 16:06 on 18 October Malta time (general live sport, not a named match), plus Rai Radio Uno/Due/Tre, Net FM and Vibe HD. On FM, **NET FM is 101 MHz** with three weekend sports slots read in full on 11 October (Friday 18:30, Saturday 16:00, Sunday 15:00 — the last two land on the Premier League kick-off windows), and Vibe FM (88.7 FM / DAB+) is the published Malta Premier League radio partner. A **US HD Radio receiver cannot decode DAB+**, and the BBC states a DAB+ radio bought in Malta is required because UK codecs differ, so buy a receiver locally or rely on analog FM. Separately, official BBC episode JSON names seven UK Premier League commentaries across 17–18 October on 5 Live / 5 Sports Extra / 5 Sports Extra 2 — Sat: Manchester City–Ipswich 15:45 Malta (5 Sports Extra), Brentford–Liverpool 16:00, Newcastle–Aston Villa 18:30; Sun: Brighton–Crystal Palace 14:55 (5 Sports Extra), Leeds–Man Utd 15:00, Bournemouth–Sunderland 15:00 (5 Sports Extra 2), Nottingham Forest–Arsenal 17:30 — with the earlier page-vs-JSON service labels resolved via episode cross-reference texts. These are UK-only schedule evidence, not Malta reception.
- **Kalshi, fixtures and eligibility:** EPL/Serie A category pages list trip-window fixtures that overlap the radio windows. Kalshi’s own help centre says trading from outside the United States is possible from many countries and that customers may use the platform while travelling abroad, subject to its Member Agreement and geographic requirements; third-party guidance conflicts, saying access is limited to US residents who pass KYC and warning of temporary geo-blocking while travelling. A market or fixture listing is still not proof of Malta radio commentary or of a market-to-broadcast link; confirm eligibility with Kalshi support.
- **Hotel environmental contribution:** the Malta Tourism Authority’s guidelines for the 1 July 2026 change confirm €1.50 per night for each guest aged 18+ (start of visit), capped at €22.50 per person per visit, disclosed separately on the invoice. The guidelines also explain the previously ambiguous “15-night” wording: the cap equals fifteen chargeable nights, so it is a cap mechanism, not an exemption for short stays. Six nights therefore implies about **€9.00 per eligible adult** — conditional on the invoice, and never prefilled in the planner.
- **Expense planner:** all budget and actual fields start blank, including the seven optional daily templates. Two tools cover the itinerary hand-off: a documented “when your itinerary arrives” intake list, and a **paste-your-itinerary quick-fill** panel that previews which row each line would fill and writes only to still-blank budget fields — typed amounts are never overwritten, and unresolved lines are reported back instead of guessed. Enter euros on a consistent whole-trip/party basis and avoid counting the same expense in an aggregate and daily row. Inputs autosave only in this browser/device, are not sent to a server, can be exported as CSV (or downloaded blank as a template), and can be cleared. Verified bus/card prices are available as a transport benchmark; reference URLs are still not quotes.
- **Customs:** duty-free allowances into Malta (€430 by air/sea on goods, plus alcohol and tobacco limits, with a lower tobacco limit possible in some member states) come from the European Union’s official travellers’ page; the return leg uses U.S. Customs and Border Protection’s $800 returning-resident exemption (48 hours abroad, once every 31 days, 200 cigarettes / 100 cigars) and its declare-everything guidance. Check the Maltese customs authority for anything unusual.
- **Research-platform limits:** sampled TripAdvisor and a small number of Google Maps profile views informed parts of the food/activities research. Yelp, Instagram, TikTok, Facebook, X, and Reddit access was blocked or limited in the recorded checks; five 403 responses in one batch lacked reliable endpoint labels. Official X post text was extracted but its attached opening-day schedule image was not readable. Coverage is not comprehensive; see the dated source notes.
- **Open questions:** TWC attendee access/entrance/times; confirmed event-day route and return; 17 October diversion impact; October single-fare validity; trip-specific TD1/hotel walking route; local FM/DAB+ reception; Rai’s dated lineup; Malta availability of BBC streaming; named-event radio carriage; business-hour/ticket conflicts; traveler-specific entry, insurance, device and booking details; 18–19 October weather; and MTA’s threshold wording. ## Build, preview, and deployment

The site is static HTML, CSS, and JavaScript with JSON data; it has no production build step or runtime dependency installation. Repository Pages settings publish the `main` branch root. Merging to `main` updates the public site through GitHub Pages. The `.nojekyll` file keeps the source/data tree static. GitHub Actions validates pull requests and pushes to `main`; the workflow is separate from Pages publishing.

For a local HTTP preview from the repository root:

```bash
python3 -m http.server 8080 --bind 0.0.0.0
# Open http://localhost:8080
```

An HTTP server is needed for browser `fetch()` and expense-planner `localStorage`. The deployed planner saves only in the current browser/device; export a CSV before switching devices or clearing browser data.

The offline validator checks JSON/schema/enums, source-log URL coverage, JavaScript syntax, topic-page/data wiring, and local paths/navigation. It is not an external URL crawler or a guarantee of current external facts.

## Browser and regression tests

Development tests use Node.js 22+, Python 3, and npm-distributed headless Chromium (Linux x64):

```bash
npm ci
npm test
```

The suite checks the eight active pages at 360/768/1440 px, responsive overflow, axe WCAG 2A/AA/2.1AA rules, data/render parity, navigation/deep links, filtering, expense persistence/CSV/reset, invalid amounts, denied/corrupt storage, and data-fetch failures. It does not test physical radio reception, external booking availability, personal eligibility, every browser/device, or exhaustive assistive-technology compatibility. Generated screenshots/reports and `node_modules` are ignored.
