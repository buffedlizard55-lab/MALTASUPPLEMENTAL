# Malta Trip Guide

A mobile-friendly, source-linked guide for the traveler-supplied trip window **13–19 October 2026**, based at **AX ODYCY, Qawra Coast Road, Qawra SPB 1902** (Deluxe Sea-View room supplied as a planning input). The traveler supplied “BLAST Arena Studios, Attard” as the event destination; this is not confirmation of a ticket, public access, exact entrance, or a TWC-specific location pin.

**Published guide:** <https://buffedlizard55-lab.github.io/MALTASUPPLEMENTAL/>

The official Thunderpick page lists the overall 2026 event window as 12–19 October (arrival 12th, media day 13th, Group Stage 14–16th, Playoffs 17–18th, departure 19th) and gives Malta as the location. A Thunderpick-issued release names BLAST Studios Malta. BLAST and venue listings provide MFCC/Ta’ Qali venue-area context for separate events, but do not confirm this traveler’s TWC spectator access, ticket, daily public door times, exact entrance, or transport. See the source log and open questions for the evidence boundaries.

This is a dated research and planning aid—not a booking, admission, fare, service, radio reception, or programme-carriage guarantee.

## Key findings and limits

- **Event and venue:** Thunderpick’s official page confirms the event window and Malta, not an address, spectator policy, entrance or public schedule. A separate-event BLAST guide and venue listings locate BLAST Arena Studios in the MFCC/Ta’ Qali area; do not transfer that event’s ticketing or entrance instructions to TWC.
- **Event-day transport and modes:** Route 186 is a direct public-bus candidate between Qawra stop 952 and Ta’ Qali Stadium stop 6227; its return boards from the opposite-side Stadium stop 2194 toward Buġibba, not the Qawra seafront. The last listed Stadium departure is 20:53 (with a last listed Buġibba Bay 1 arrival at 21:27); this is not a hotel connection guarantee. Route 214 is an alternative to compare. MPT lists an evening Route 186 diversion on 17 October. TD1’s official timetable lists Il-Qawra Arznell stop 950 in both directions; trip-specific departure choice and the walk to AX ODYCY still need a planner check. Compare bus fares/cards with live taxi/ride-hailing quotes and full car-hire costs; the October 2026 single fare and exact event-day door-to-door route remain open.
- **Sports radio:** NET FM is listed at FM 101 MHz with a recurring sports grid. Malta DAB+ listings include BBC World Service, Rai Radio Uno and Radio Sportiva; WorldDAB lists BBC World Service on Digi B block 6A (181.936 MHz). BBC episode JSON gives *Sportsworld* first-broadcast offsets that convert to 15:06 on 17 October and 16:06 on 18 October Malta time. This is general live sport, not a named-match schedule. Six BBC Radio 5 Live / 5 Sports Extra Premier League episode records are UK schedule evidence only; two upcoming-page service labels differ from their JSON parent-service fields and should be rechecked. No Malta reception, stream access or named-match carriage was verified.
- **Kalshi and fixtures:** EPL/Serie A category pages were checked for trip-window listings and schedule overlap. A market or fixture listing is not proof of Malta radio commentary, trading eligibility, or a market-to-broadcast link. Those questions remain open.
- **Hotel environmental contribution:** Malta Tourism Authority guidance states €1.50 per night per person aged 18+ from 1 July 2026, capped at €22.50 per eligible person per visit. Its separate “15-night threshold” wording is ambiguous; any six-night arithmetic is conditional, not a booking charge. Check the hotel invoice; the planner does not prefill a personal amount.
- **Expense planner:** all budget and actual fields start blank, including the seven optional daily templates. Enter euros on a consistent whole-trip/party basis and avoid counting the same expense in an aggregate and daily row. Inputs autosave only in this browser/device, are not sent to a server, can be exported as CSV, and can be cleared. Reference URLs are not price quotes.
- **Research-platform limits:** sampled TripAdvisor and a small number of Google Maps profile views informed parts of the food/activities research. Yelp, Instagram, TikTok, Facebook, X, and Reddit access was blocked or limited in the recorded checks; five 403 responses in one batch lacked reliable endpoint labels. Official X post text was extracted but its attached opening-day schedule image was not readable. Coverage is not comprehensive; see the dated source notes.
- **Open questions:** TWC attendee access/entrance/times; confirmed event-day route and return; 17 October diversion impact; October single-fare validity; trip-specific TD1/hotel walking route; local FM/DAB+ reception; Rai’s dated lineup; Malta availability of BBC streaming; named-event radio carriage; business-hour/ticket conflicts; traveler-specific entry, insurance, device and booking details; 18–19 October weather; and MTA’s threshold wording. See [`docs/OPEN_QUESTIONS.md`](docs/OPEN_QUESTIONS.md).

## Build, preview, and deployment

The site is static HTML, CSS, and JavaScript with JSON data; it has no production build step or runtime dependency installation. Repository Pages settings publish the `main` branch root. Merging to `main` updates the public site through GitHub Pages. The `.nojekyll` file keeps the source/data tree static. GitHub Actions validates pull requests and pushes to `main`; the workflow is separate from Pages publishing.

For a local HTTP preview from the repository root:

```bash
python3 -m http.server 8080 --bind 0.0.0.0
# Open http://localhost:8080
```

An HTTP server is needed for browser `fetch()` and expense-planner `localStorage`. The deployed planner saves only in the current browser/device; export a CSV before switching devices or clearing browser data.

The offline validator checks JSON/schema/enums, source-log URL coverage, JavaScript syntax, topic-page/data wiring, and local paths/navigation. It is not an external URL crawler or a guarantee of current external facts.

## Browser and regression tests

Development tests use Node.js 22+, Python 3, and npm-distributed headless Chromium (Linux x64):

```bash
npm ci
npm test
```

The suite checks the eight active pages at 360/768/1440 px, responsive overflow, axe WCAG 2A/AA/2.1AA rules, data/render parity, navigation/deep links, filtering, expense persistence/CSV/reset, invalid amounts, denied/corrupt storage, and data-fetch failures. It does not test physical radio reception, external booking availability, personal eligibility, every browser/device, or exhaustive assistive-technology compatibility. Generated screenshots/reports and `node_modules` are ignored.
