# Malta Trip Guide

A mobile-friendly, source-linked travel guide for the trip window **13–19 October 2026**, based at the user-supplied **AX ODYCY, Qawra Coast Road, Qawra SPB 1902** (Deluxe Sea-View room). The event location supplied by the traveler is **BLAST Arena Studios, Attard**.

**Published guide:** <https://buffedlizard55-lab.github.io/MALTASUPPLEMENTAL/>

The official Thunderpick page rechecked on 11 October lists the overall 2026 event window as 12–19 October (arrival 12th, media day 13th, Group Stage 14–16th, Playoffs 17–18th, departure 19th) and the Thunderpick-issued release names BLAST Studios Malta. That venue's published address — MFCC South Gate National Stadium, Millennium Stand, Attard ATD 4000 — was corroborated on 11 October by the Malta Tourism Authority directory, GamingMalta, the ticket agent Eventworks and BLAST's own attendee guide for another BLAST event at the same venue. The organizer has not published this traveler's spectator access, ticket terms, daily public door times or the event-specific entrance; those remain open.

This is a dated research and planning aid, not a booking or guarantee of future opening hours, fares, availability, event access, radio reception, or programme carriage.

## Key findings and limits

- **Event and venue:** the official Thunderpick page lists the 12–19 October event window and Malta as its location, and the Thunderpick release names BLAST Studios Malta. The venue address (MFCC South Gate National Stadium, Millennium Stand, Attard ATD 4000) is corroborated by three independent listings, and BLAST's attendee guide for another event at the same venue gives the same MFCC/Ta' Qali address; the event-to-venue link and the event-specific gate rest on the organizer's naming and remain unconfirmed, as do public spectator access, ticket arrangements and door times.
- **Event-day transit:** Route 186 is the leading public-bus corridor between Qawra and Ta' Qali; Route 214 is an alternate to compare. MPT's static listing shows Qawra stop 952 at 06:09–21:39 at 30-minute intervals (checked 11 Oct; a parallel table variant shows 06:10–21:38), and its stop-level tables show the last evening passes on the Mosta stretch at about 21:53–21:55. The normal Rabat-to-Buġibba return runs via St Paul's Bay/Buġibba rather than the Qawra seafront — this is not a guaranteed hotel return. MPT lists a Route 186 diversion weekly on Friday and Saturday 19:00–00:00 starting 17 October (toward Buġibba, stops Gholja 2 to Targa skipped). Night buses are confirmed for Buġibba (N212) and Valletta (N13) but no night route serving Ta' Qali was verified: plan a taxi/ride-hailing backup for late exits and confirm stops, walking segments and the live timetable close to travel.
- **Radio:** NET FM is listed at FM 101 MHz and publishes a recurring grid (Saturday “Hits & Score” 16:00, Sunday “Sports Box” 15:00, Friday “Mhux Premier biss” 18:30) whose content is not described, so commentary is unproven. WorldDAB lists three Maltese DAB+ multiplexes — 6A (181.936 MHz), 6C (185.360 MHz) and 12A (223.936 MHz). BBC World Service and Rai Radiouno (Italian football commentary on weekends) are listed on 6A; 12A carries a service named “Sports Channel” whose broadcaster is unknown. Radio Sportiva appears in Digi B's directory but not in WorldDAB's multiplex lists, and no block or frequency was found — treat it as a service to scan for, not confirmed carriage. The BBC Radio 5 Live Premier League listing is UK-based and its weekend entries were undated in the snapshot checked (OQ-24). Reception at the hotel and venue is untested and no fixture-specific carriage was confirmed.
- **Hotel environmental contribution:** Malta Tourism Authority guidance checked 10 October states €1.50 per night per person aged 18+ from 1 July 2026, capped at €22.50 per eligible person per visit. Six chargeable nights would be €9 per eligible adult, conditionally; actual billable nights, guest ages, and the hotel invoice determine the amount. The planner does not prefill a personal charge.
- **Trip-week fixtures (context only):** the trip window contains an English Premier League matchweek (17–18 October), Europa League matchday 2 (Thursday 15 October) and an NFL Sunday (18 October, including a 15:30 Malta-time London game). These are recorded in the radio dataset as fixture context: a fixture is not evidence that a station carries it.
- **Expense planner:** all budget and actual amounts start blank. Seven day-by-day rows and an itinerary-notes box were added on 11 October so a supplied itinerary can be costed day by day; day totals and a grand total are shown separately from the category rows to avoid double counting. Enter amounts in euros on a consistent whole-trip/party basis. The planner stores inputs in this browser/device only, does not send them to a server, exports a CSV backup, and can clear saved entries. Reference URLs are not price quotes.
- **Research-platform limits:** sampled TripAdvisor and a small number of Google Maps profile views informed parts of the food/activities research. Direct Yelp, Instagram, TikTok, Facebook, and X requests, and Reddit refreshes, were blocked or returned HTTP 403 in the relevant checks. Platform coverage is not comprehensive; see the dated notes in `docs/SOURCES.md` and the topic pages.
- **Open questions:** exact event access/times, saved date-specific transit route and return, 17 October diversion impact, trip-week radio schedule/carriage, current business hours/status conflicts, traveler-specific entry/insurance/device details, and the booking itinerary remain unresolved as noted in `docs/OPEN_QUESTIONS.md`.

## Build, preview, and deployment

The site is static HTML, CSS, and JavaScript with JSON data; no application build or dependency installation is required. Repository Pages settings checked on 9 October 2026 publish the `main` branch root to the public site. Merging changes to `main` updates the site through GitHub Pages’ existing branch-based publishing. The `.nojekyll` file keeps the source/data tree static. A GitHub Actions workflow validates pull requests and pushes to `main`; it does not replace the configured Pages publisher.

For a local HTTP preview from the repository root:

```bash
python3 -m http.server 8080
# Open http://localhost:8080
```

An HTTP server is needed for browser `fetch()` and the expense planner’s `localStorage` behavior. The deployed planner saves only in the current browser/device; export a CSV before switching devices or clearing browser data.

The Pages workflow and local validator check the exact 13-field record schema and enums, HTTPS primary URLs and their source-log coverage, JavaScript syntax, topic-page/data wiring, and local links. External websites are not guaranteed to remain available; re-open primary sources before acting on date-sensitive information.
