## Not covered by the automated gate

* External URL liveness: the validator only proves that a URL is logged, not that the remote page answers today.
* Real-device rendering: responsive CSS and the new planner rows were reviewed in code, not screenshotted on a real phone.
* Radio reception: no DAB+/FM receiver test was possible at the hotel or venue.
